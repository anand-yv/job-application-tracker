# Frontend

Stack: React 19, Vite 8, react-router-dom 7, Tailwind CSS 4, shadcn/ui
(style `base-nova`, built on `@base-ui/react`), axios, lucide-react icons.
Plain JavaScript (no TypeScript). Page/component styling uses CSS Modules
(`*.module.css`); shadcn components use Tailwind classes. `@` is aliased to
`src/` (`vite.config.js`, `jsconfig.json`).

Provider tree (`main.jsx`): `BrowserRouter` → `ThemeProvider` → `AuthProvider` → `App`.
`App` renders `Headers` above the `<Routes>`.

---

## Routes (`src/App.jsx`)

| Path | Guard | Component (file) | Status |
|---|---|---|---|
| `/` | — | `<Navigate to="/login" replace>` | Redirect (then `GuestRoute` sends logged-in users to `/dashboard`) |
| `/login` | `GuestRoute` | `Login` (`pages/Login.jsx`) | Working |
| `/register` | `GuestRoute` | `Register` (`pages/Register.jsx`) | Working; password-match check is client-side only |
| `/dashboard` | `ProtectedRoute` | `Dashboard` (`pages/Dashboard.jsx`) | Working — application list, status filter, sort by applied date / company, asc/desc, pagination (10/page) |
| `/applications/new` | `ProtectedRoute` | `ApplicationForm` (`pages/ApplicationForm.jsx`) | Working — create with contact multi-select |
| `/applications/:id` | `ProtectedRoute` | `ApplicationDetail` (`pages/ApplicationDetail.jsx`) | Working — view, edit/save/cancel, delete, inline status change in view mode, contact linking |
| `/contacts` | `ProtectedRoute` | `Contact` (`pages/Contact.jsx`) | Working — list, refresh, "Create contact" |
| `/contacts/new` | `ProtectedRoute` | `ContactForm` (`pages/ContactForm.jsx`) | Working |
| `/contacts/:id` | `ProtectedRoute` | `ContactDetails` (`pages/ContactDetail.jsx`) | Working — view, edit/save/cancel, delete. Doesn't show linked applications |
| `*` | — | `NotFound` (`pages/NotFound.jsx`) | Static 404 page |

Both guards only check that a token exists in `localStorage`; validity is
enforced by the axios 401 interceptor.

## Reusable components (`src/components/`)

| Component | What it does | Built on |
|---|---|---|
| `Headers` | App header: logo (→ `/dashboard`), "CONTACTS" button (logged in only), theme toggle, avatar menu with Logout + confirmation dialog; Login/Register links for guests | shadcn `Button`, `DropdownMenu`, `Dialog` + `Headers.module.css` |
| `Dropdown` | Generic single-select. Props: `id`, `value`, `onChange(value)`, `options: [{value, label}]`, `placeholder`, `disabled` | Thin wrapper over shadcn `Select` |
| `ContactMultiSelect` | Multi-select of contacts. Trigger shows selected names as chips; popover lists "company \| name" with a check mark; closes on outside click. Props: `allContacts`, `selectedIds`, `onChange(contactId)` (toggle), `disabled` | Custom (own state, popover, outside-click handling, `ContactMultiSelect.module.css`); uses shadcn `Button` as trigger and lucide `Check` |
| `routing/ProtectedRoute` | Renders `<Outlet/>` if a token exists, else redirects to `/login` | Custom (react-router) |
| `routing/GuestRoute` | Redirects to `/dashboard` if a token exists, else renders `<Outlet/>` | Custom (react-router) |

### shadcn/ui primitives (`src/components/ui/`)

Generated by the shadcn CLI on Base UI. Used: `button`, `input`, `label`,
`textarea`, `select`, `dialog`, `dropdown-menu`. Unused: `card` (see
[dead-code.md](dead-code.md)). Helper: `lib/utils.js` → `cn()` (clsx + tailwind-merge).

## Contexts (`src/context/`)

| Context | Hook | Exposes | Behaviour |
|---|---|---|---|
| `AuthContext` | `useAuth()` | `user`, `authLoading`, `fetchUser()`, `logout()` | On mount, if a token exists, calls `GET /auth/me` and stores the result in `user`; on failure clears the token. `logout()` removes the token, clears `user`, navigates to `/` |
| `ThemeContext` | `useTheme()` | `theme`, `toogleTheme()` | Light/dark theme. Initial value from `localStorage` (`theme`) or system preference. Toggles the `dark` class on `<html>` and persists the choice |

Constants (`src/constant.js`): `TOKEN_KEY = "access_token"`, `THEME_KEY = "theme"`,
`LIGHT_THEME`, `DARK_THEME`.

## API layer

### `src/api/axiosInstance.js`

- `baseURL: import.meta.env.VITE_API_URL`, `timeout: 5000`, JSON content type.
- Request interceptor: attaches `Authorization: Bearer <token>` unless the URL
  is `/auth/login` or `/auth/register`.
- Response interceptor: on `401` for a request that carried a token, removes
  the token and hard-redirects to `/login`.

### Service files (`src/services/`)

**`auth.js`** — `auth`

| Function | HTTP call |
|---|---|
| `login({ email, password })` | `POST /auth/login` |
| `register({ email, password })` | `POST /auth/register` |
| `getMe()` | `GET /auth/me` |

**`applications.js`** — `applications`

| Function | HTTP call |
|---|---|
| `getAll(params)` | `GET /applications` with `{ page, size, status, sort }` |
| `getById({ id })` | `GET /applications/{id}` |
| `create(data)` | `POST /applications` |
| `update(id, data)` | `PUT /applications/{id}` |
| `deleteById(id)` | `DELETE /applications/{id}` |
| `statusChange(id, data)` | `PATCH /applications/{id}/status` |

**`contactService.js`** — `contactService`

| Function | HTTP call |
|---|---|
| `getAll()` | `GET /contacts` |
| `getById(id)` | `GET /contacts/{id}` |
| `createContact(data)` | `POST /contacts` |
| `updateContactById(id, data)` | `PUT /contacts/{id}` |
| `deleteContactById(id)` | `DELETE /contacts/{id}` |

Every frontend call maps to an existing backend endpoint
([api-endpoints.md](api-endpoints.md)).
